경계 정보를 어노테이션에 살리는 방법 후보: (a) 신규 마커(/M 류) 도입 + 특수규칙 신설 (b) 어절(공백) 삽입으로 기존 경로 재사용 (c) idioms 정규식(`못[아-히]`→`못 \1`) — (c)는 못이(명사+조사)와 못 잊다(부사+동사)가 표면에서 동일해 기각(POS 없이 불가능), (a)는 마커 제거 순서(Step 6에서 테이블 규칙 전에 스트립)와 충돌해 테이블 재배치가 필요해 과공학 — (b) 채택: 띄어 쓴 입력(`못 알아먹는다`→`모 다라멍는다`)이 이미 제9항 테이블(`ᆺ`+공백→`ᆮ`)+link3(`ᆮ ᄋ`→` ᄃ`)으로 표준 발음을 내고 있으므로, 조건을 만족하는 경계에 공백만 넣으면 붙은 입력이 띈 입력과 완전히 같은 길을 흐른다. 조건 설계의 핵심은 과잉 적용 방지: 왼쪽이 부사(MAG/MAJ) + ㄷ류 종성(ㄷ,ㅅ,ㅆ,ㅈ,ㅊ,ㅌ — 다른 받침은 단어내/밖 결과가 동일) + 다음 형태소가 ㅇ-모음 시작 '실질'형태소(복합태그 VV+EF도 어간 V가 보이면 실질로 인정). 조사·어미·접미사(J*/E*/X*) 앞은 제13항 연음이 맞으므로 제외(잘못을[잘모슬], 옷이[오시]), 합성어 ㄴ첨가(제29항)는 부사 경계가 아니므로 애초에 무충돌.

### 판정
가설 확정. 국립국어원 답변이 제15항을 못 사례의 근거로 명시('못 올 일이'[모돌 이리]) — 부정부사 '못'은 별개 단어라 ㅅ이 어말 대표음 [ㄷ]으로 실현되고, 뒤 실질형태소가 모음으로 시작하면 그 [ㄷ]이 옮겨 붙는다. (b)의 공백 삽입으로 Dart mecab-on이 Python 원본보다 표준에 가까워진다(나랏일 Case 1에 이은 두 번째 우위 — 원본은 붙은 못알아먹는다도 모사라멍는다). ㅣ-초성은 국립국어원이 [몬니저](ㄴ첨가 허용)/[모디저](두 단어 읽기) 이중 발음을 인정하는데 본 구현은 기본형([모디저]류)만 낸다. 항목 4(연음 재분절 표기)도 이 기회에 판정: Python 원본 regular.py의 link1/link3이 Dart와 동일하게 자음이동+ㅇ삭제(`ᆺᄋ→ㅅ`, `ᆺ ᄋ→ ᄉ`) — 소스와 실측('못 알아먹는다'→'모 다라멍는다' 양쪽 동일)으로 확인, g2pk2의 받침유지+ㅇ 명시만 다를 뿐 음소열 동일. 변경 불필요. 잔여 결함 클래스(별개 카드감): 합성어 내부 제15항 일반(맛없다[마덥다]를 link1이 [마십다]로 — NNG+VA 경계, 부사 아님)은 이번 범위 밖.

### 조치
